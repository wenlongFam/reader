# 文龙阅读器 · 产品设计文档（PRD-Lite）

> 版本：v0.1 · 2026-10-29
> 配套技术方案：[mvp-tech-plan.md](mvp-tech-plan.md)

---

## 1. 产品定位

**一款干净、快、只管读书的本地电子书阅读器。**

- 一句话：把书导进来，舒服地读完，不弹广告、不催登录、不引流。
- 目标用户：手里囤了一堆 TXT / EPUB 本地书（尤其网文 TXT 全本）、被广告和会员打扰搞烦了的重度阅读者。
- 平台：Android / iOS 双端（Flutter 一套代码）。

## 2. 核心价值主张

| 痛点 | 我们的回答 |
|---|---|
| 网文 TXT 乱码、打不开、章节错乱 | GBK/UTF-8 自动识别 + 流式分章，100MB 全本秒开 |
| 阅读器广告多、功能臃肿 | 零广告零注册，界面只有书和阅读 |
| 断点续读不准 | 进度精确恢复到章节内位置 |

## 3. MVP 功能范围

### 3.1 功能清单

| # | 功能 | 描述 | 优先级 |
|---|---|---|---|
| F1 | 书籍导入 | 系统文件选择器导入 TXT / EPUB；支持系统"用其他应用打开"接收文件 | P0 |
| F2 | 书库 | 封面/列表视图、最近阅读排序、长按删除（不删原文件） | P0 |
| F3 | 阅读器 | 上下滚动 + 左右翻页两种模式；翻页动画覆盖式 | P0 |
| F4 | 阅读设置 | 字号 14~28、行距、白/米黄/夜间三主题、亮度 | P0 |
| F5 | 断点续读 | 退出再进恢复到章节内位置，无需手动寻找 | P0 |
| F6 | 章节目录 | 底部上滑抽屉，章节列表 + 跳转 | P1 |
| F7 | 书签 | 当前位置一键加书签、书签列表跳转 | P1 |
| F8 | TXT 编码修正 | 乱码时手动切换编码重新解析 | P2 |

### 3.2 明确不做（v1 边界）

在线书城 / 书源、笔记划线批注、云同步与账号、TTS 朗读、社区书单、内购广告。

> 判断标准：与"把本地一本书读完"无关的，一律不做。

## 4. 主要用户流程

```
首次启动 → 空书库引导页 → 导入文件 → 书库出现书籍
   ↓
点击书籍 → 自动定位上次进度 → 阅读
   ↓
阅读中：呼出菜单 → 调字号/换主题 / 看目录 / 加书签
   ↓
退出 → 进度自动保存 → 下次打开继续
```

## 5. 关键体验原则

1. **打开书 1 秒内见正文**——大文件靠偏移索引按需加载，不整本加载。
2. **设置即改即见**——字号/主题切换实时重排，不闪不跳。
3. **进度永远不丢**——翻页、切章、退后台、杀进程四个时机都落库。
4. **单手可达**——核心操作（翻页、呼出菜单）集中在屏幕下半区。

## 6. MVP 验收标准（摘要）

- 导入 10 本混合编码 TXT（含 GBK、100MB+ 全本）：不乱码、不崩溃、章节识别率 ≥ 90%。
- EPUB 正常书 5 本：目录完整、正文可读。
- 断点续读：任意时刻杀进程后重进，回到原位置。
- 三主题 + 字号调节下重排正确，无文字截断。

## 7. 里程碑

M0 脚手架（✅ 已完成）→ M1 导入+书库 → M2 阅读器核心 → M3 阅读体验 → M4 打磨提审。
详细排期与验收见技术方案文档。
