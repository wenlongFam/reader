# 文龙阅读器（wenlong_reader）MVP 技术方案

> 版本：v0.1 · 2026-10-29  
> 目标：双端（Android / iOS）、本地导入、网文 TXT 居多的最小可用电子书阅读器。

---

## 1. 结论先行

| 决策项     | 选型                     | 理由                                                                           |
| ------- | ---------------------- | ---------------------------------------------------------------------------- |
| 技术栈     | **Flutter (Dart 3.x)** | 双端一套代码；阅读器核心是文本排版分页，Flutter 自绘渲染（TextPainter / Canvas）远比 RN 的桥接方案可控；性能满足长文滚动 |
| 状态管理    | **Riverpod**           | 编译期安全、无 BuildContext 依赖、适合"阅读器引擎"这类非 UI 状态（分页结果、进度）                          |
| 本地存储    | **drift (SQLite)**     | 书籍元数据、章节索引、阅读进度；成熟稳定、支持复杂查询，比 Isar 维护风险低                                     |
| 路由      | **go_router**          | 书库 / 阅读器 / 设置三页足够，声明式即可                                                      |
| EPUB 解析 | **archive + 自封装轻量解析**  | EPUB 本质是 zip + XHTML，MVP 不引入重型依赖，只提取标题/章节/纯文本                                |
| TXT 解析  | **自研：编码探测 + 流式分章**     | 网文 TXT 的 GBK 编码、超大文件是核心痛点，必须自研健壮处理（详见 §4）                                    |

---

## 2. MVP 功能范围（对齐前文讨论）

1. 书籍导入：系统文件选择器导入 `.txt` / `.epub`
2. 书库：封面列表、最近阅读排序、长按删除
3. 阅读器：翻页（覆盖式左右翻 + 上下滚动两种模式）、字号调节、白/米黄/夜间三种主题、亮度调节
4. 阅读进度：自动记录、秒级恢复
5. 跳章 + 书签：章节目录抽屉、底部进度条拖动、简单书签

**明确不做**：在线书源、笔记划线批注、云同步、TTS、社区分享。

## 3. 模块划分（目录结构）

```
lib/
├── main.dart
├── app.dart                      # MaterialApp + 主题 + 路由
├── core/                         # 通用基础设施
│   ├── db/                       # drift 表定义与 DAO（Book/Chapter/Progress/Bookmark）
│   ├── theme/                    # 阅读主题（背景/文字色/行距 token）
│   └── util/                     # 编码探测、字符串工具
├── features/
│   ├── import/                   # 文件导入：选择器 → 解析 → 入库
│   │   ├── data/txt_parser.dart      # TXT：编码探测 + 分章
│   │   ├── data/epub_parser.dart     # EPUB：解包 + 章节抽取
│   │   └── domain/import_service.dart
│   ├── library/                  # 书库页
│   │   └── presentation/library_page.dart
│   ├── reader/                   # 阅读器（核心模块）
│   │   ├── engine/
│   │   │   ├── paginator.dart        # 分页引擎：文本 → 页面切片
│   │   │   └── page_painter.dart     # 自绘页面（TextPainter 渲染）
│   │   └── presentation/
│   │       ├── reader_page.dart      # 手势翻页 / 滚动容器
│   │       ├── reader_settings.dart  # 字号/主题/亮度面板
│   │       └── chapter_drawer.dart   # 章节目录
│   └── settings/                 # 全局设置（MVP 可只挂阅读偏好）
└── l10n/                         # 预留 i18n
```

架构采用轻量分层：`presentation → domain(service) → data(parser/db)`，MVP 不上完整 Clean Architecture，避免过度设计。

## 4. 核心技术要点

### 4.1 TXT 解析（MVP 投入重心）

- **编码探测**：读前 4KB 做 BOM 检查（UTF-8/UTF-16LE/BE）；无 BOM 则用 `charset_converter` / 内置启发式判 UTF-8 有效性，失败即按 **GBK** 解码（国内网文 TXT 绝大多数是 GBK）。解析后保留原文件引用，允许用户手动切编码重新解析。
- **大文件**：不做一次性全文读入内存。用 `RandomAccessFile` 分块流式读取，边读边按章节正则切分：
  - 章节正则：`^\s*(第[零一二三四五六七八九十百千万\d]+[章节卷回集部]|Chapter\s+\d+).*` 覆盖 90% 网文；连续匹配失败则降级为按固定行数（如 200 行）虚拟分章。
  - 章节只存 **(title, 起始字节偏移)** 进 SQLite，正文按需读取——100MB 全本也能秒开。
- **分页引擎**：按当前字号/行距/屏幕尺寸用 TextPainter 逐段测量排版，生成页面切片并缓存；设置变更（字号/主题）触发整书重排。翻页动画用覆盖式 + 视差，滚动模式用 `Scrollable` 复用列表。

### 4.2 EPUB 解析

zip 解包 → 读 `container.xml` 找 OPF → 按 spine 顺序抽取章节 → 剥离 HTML 标签取纯文本（MVP 不做富文本/图片渲染，说明：EPUB 在 MVP 中按"结构化 TXT"处理）。

### 4.3 进度与恢复

进度记录粒度：`(bookId, chapterIndex, chapter 内字符偏移)`。切页/切章/退后台/退应用四时机写库；打开书时按偏移重排后定位页面。

## 5. 里程碑

| 阶段             | 内容                                | 产出验收                                |
| -------------- | --------------------------------- | ----------------------------------- |
| **M0 工程脚手架**   | Flutter 工程、目录、路由、drift 表、主题 token | 空壳 App 三页可跳转                        |
| **M1 导入 + 书库** | TXT/EPUB 解析入库、书库列表/删除             | 导入 10 本混合编码 TXT（含 GBK、100MB+）不乱码不崩溃 |
| **M2 阅读器核心**   | 分页引擎、翻页/滚动、进度记录恢复                 | 断点续读精确到段落                           |
| **M3 阅读体验**    | 字号/主题/亮度、章节目录、书签                  | 三主题下重排正确                            |
| **M4 打磨提审**    | 异常兜底、双端真机适配（刘海屏/返回手势）、隐私政策        | 可出包提审                               |

## 6. 风险与对策

| 风险                      | 对策                                 |
| ----------------------- | ---------------------------------- |
| 奇葩 TXT 格式（无章节规律、全角空格混排） | 分章降级策略 + 手动选章兜底                    |
| iOS 文件导入入口（用户不知道在哪导书）   | 首次启动引导页 + 支持"用其他应用打开"（Open In）接收文件 |
| 分页引擎在极端长段落上的性能          | 限制单章预分页范围，滚动模式降级为流式排版              |
| drift / Riverpod 版本迭代   | 锁定版本，升级走 M4 后窗口                    |
